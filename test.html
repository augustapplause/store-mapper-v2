How to use

Place test.html, test.js, and the provincial DA JSON files in the same repository/folder. Load the same Excel/CSV/JSON store file used by Store Explorer, then run the benchmark. Excel files use SheetJS exactly like the main app: the first worksheet is read, the header row is detected, and rows are normalized before the benchmark runs.
